01

Tableau de bord

La page d'accueil est votre point de départ. Elle affiche toutes vos sessions de sport — passées et à venir — sous forme de cartes. Chaque carte indique le sport, le lieu, la date et le statut de la session (ouverte, complète, terminée).

Pour retrouver vos matchs sur n'importe quel appareil, entrez votre email dans le champ en haut de page. Vos sessions y seront associées et récupérées automatiquement à chaque connexion.

💡 Tapez sur une carte de match pour accéder directement à la session et voir son avancement détaillé.
🃏
Vue cartes
Affichage par défaut, toutes les sessions triées par date.
📅
Vue agenda
Regroupement par semaine, pratique pour voir plusieurs sessions d'un coup.
➕
02

Créer une session

Appuyez sur le bouton + en bas à droite de l'écran pour créer une nouvelle session. Un identifiant unique est généré automatiquement — c'est lui qui permet à vos amis de rejoindre la même session.

  1. Appuyez sur + ou sur "Nouvelle session" depuis le tableau de bord.
  2. Renseignez vos disponibilités dans la grille (étape 1).
  3. Proposez ou votez sur des créneaux de terrain (étape 2).
  4. Finalisez les infos de la session et gérez les inscrits (étape 3).
🔁 Le bouton 🔁 Session récurrente depuis l'accueil génère automatiquement une série de séances hebdomadaires sur plusieurs semaines — pratique pour les entraînements réguliers.
ℹ️ Chaque clic sur + crée une session différente avec un nouvel identifiant. Pour revenir à une session existante, utilisez son lien partageable ou le tableau de bord.
🗓
03

Disponibilités

La grille de disponibilités (étape 1) permet à chaque joueur d'indiquer ses créneaux libres sur la semaine en cours. Elle fonctionne sur le principe d'un tableau : une ligne par jour, une colonne par créneau (Matin, Après-midi, Soir).

Pour chaque cellule, trois états sont possibles :

✅
Disponible
Ce créneau vous convient.
❌
Indisponible
Vous êtes pris(e) à ce moment.
  1. Renseignez votre prénom dans le champ en haut de la grille.
  2. Sur mobile : tapez une cellule pour choisir disponible / indisponible.
  3. Sur desktop : survolez une cellule pour voir les boutons apparaître.
  4. Utilisez SEMAINE ou WEEK-END pour remplir plusieurs jours en une seule action.
💡 Le panneau Créneaux communs sous la grille calcule automatiquement les meilleurs moments pour tout le groupe, classés par nombre de participants disponibles.
🔄 Les disponibilités sont synchronisées toutes les 30 secondes. Les petits points colorés sur les cellules indiquent les réponses des autres joueurs.
⏰
04

Proposer des créneaux de terrain

L'étape 2 permet de proposer des créneaux concrets : date, heure, lieu et prix. Deux méthodes pour les ajouter :

✦
Smart Parser
Collez le texte d'une annonce de réservation (copié depuis un site de terrain). L'IA extrait automatiquement les dates, horaires et prix.
➕
Manuel
Ajoutez un créneau manuellement via le formulaire : date, début, fin, lieu, prix.

Une fois les créneaux listés, chaque joueur peut voter 👍 pour ceux qui lui conviennent. Un seul vote par joueur par créneau — re-cliquer annule le vote. Le score affiché reflète le nombre de joueurs ayant voté pour ce créneau.

🌤 La météo de la semaine s'affiche sous les créneaux — cliquez sur un jour pour voir les prévisions heure par heure (températures et précipitations).
📋
05

Finaliser la session

L'étape 3 centralise toutes les infos de la session : lieu, date, sport, prix, adresse, lien Maps, lien de réservation et notes. Recherchez un club dans le champ dédié pour pré-remplir ces champs automatiquement.

Gestion des inscrits : ajoutez les joueurs par prénom. Quand la liste est pleine (max joueurs atteint), les suivants sont automatiquement placés en liste d'attente et promus si quelqu'un se désiste.

📊
Export Excel
Téléchargez la liste des inscrits + les infos de session en .xlsx.
📅
Export Calendrier
Téléchargez un fichier .ics pour ajouter l'événement à Google Calendar, Apple Calendar ou Outlook.
🏟 Si la session est liée à un club de l'annuaire, un bouton 🏟 Voir le club apparaît dans les infos — il ouvre directement la fiche du club avec toutes ses informations.
🏟
06

Annuaire des clubs

L'onglet 🏟 Clubs liste tous les clubs disponibles. Filtrez par sport (Padel, Squash, Tennis, Badminton, Pickleball, Five…), recherchez par nom ou adresse, et consultez la fiche détaillée de chaque club.

Chaque fiche club contient : sports pratiqués, horaires d'ouverture, tarifs, détail des installations (nombre de terrains par surface, couverts / découverts), téléphone, site web, lien Google Maps.

♥
Favoris
Cliquez sur ♥ pour marquer un club. Retrouvez vos favoris dans l'onglet dédié — sauvegardé sur votre appareil.
📝
Notes locales
Ajoutez vos propres notes sur un club (stationnement, contact…). Sauvegardé uniquement sur votre appareil.
📍 Entrez votre adresse dans la barre de recherche de distance et cliquez Valider pour trier les clubs par proximité. Les durées de trajet en voiture s'affichent automatiquement.
ℹ️ Depuis la fiche d'un club, le bouton 🏅 Organiser un match ici pré-remplit automatiquement les informations de la session (lieu, sport, max joueurs…).
🔗
07

Partager une session

Chaque session a un lien unique. Partagez-le à vos amis pour qu'ils accèdent directement à la session et renseignent leurs disponibilités — sans inscription ni compte nécessaire.

  1. Ouvrez la session (vue 📋 Session).
  2. Appuyez sur le bouton 🔗 au-dessus du +.
  3. Sur mobile : le partage natif s'ouvre (SMS, WhatsApp, email…).
  4. Sur desktop : le lien est copié dans le presse-papiers.
💡 L'URL de la page contient l'identifiant de session. Vous pouvez aussi copier directement la barre d'adresse de votre navigateur.
🔄 Les disponibilités se synchronisent automatiquement toutes les 30 secondes. Vos amis voient vos réponses en temps réel, et vice-versa — sans recharger la page.
⚙️
08

Profil & synchronisation

L'onglet ⚙️ Profil permet de configurer votre identité dans l'app :

  • Prénom — affiché sur la grille de disponibilités pour que les autres joueurs vous reconnaissent.
  • Email — associe votre compte aux sessions pour les retrouver depuis n'importe quel appareil.

La synchronisation s'effectue avec un Google Sheet partagé, qui sert de base de données commune pour votre groupe. Une synchro automatique a lieu à chaque ouverture de l'app.

🔄 Le bouton Actualiser dans la barre en bas de chaque page force une synchronisation manuelle immédiate — utile si vous venez de partager la session et voulez voir les réponses des autres.
📵 En mode hors ligne, l'app fonctionne en lecture seule. Vos modifications seront synchronisées automatiquement dès le retour de la connexion.
